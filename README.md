# COSMOS // 宇宙观测站

程序化 WebGL 序章 + 六章节交互网站。Vite、React、Three.js、React Three Fiber、GLSL、GSAP ScrollTrigger 与 Lenis；不依赖外部天体图片、模型、字体或音频文件。

## 运行

需要 Node.js 20.19+ 或 22.12+ 和支持 WebGL 2 的浏览器。

```sh
npm ci
npm run dev
```

直接打开 `http://localhost:5173/#observatory` 进入正式网站；不带 hash 的 `/` 从序章开始。

```sh
npm run check:routes
npm run build
npm run preview
```

## 操作与内容

序章中点击、Enter 或 Space 推进地球、冰环、星云、黑洞与银河。单段 3.5 秒，播放期间锁定推进输入。银河阶段向下滚轮、触摸板下滑或手机上划，沿核心掠过，进入正式网站。M 切换 Web Audio 合成氛围音，默认静音。

正式网站由六章组成，支持连续滚动、反向回看、章节导航和直达链接：

| 地址           | 介绍与交互                                         | 下一段衔接                                            |
| -------------- | -------------------------------------------------- | ----------------------------------------------------- |
| `#observatory` | 日蚀观测站入口                                     | 从遮住恒星的行星边缘滑出，逐渐揭开光球                |
| `#light`       | 恒星与核聚变；温度滑杆改变星光颜色                 | 近掠光球、热扰动，再沿同一空间的弧线路径返回环面      |
| `#rings`       | 冰粒、尘埃与岩屑；调节观察倾角                     | 降到倾斜环面，通过真实 Cassini 间隙，环粒产生近远视差 |
| `#nursery`     | 恒星诞生与暗尘；鼠标或轻触探照                     | 穿过固定于世界坐标的尘柱，沿尘隙接近吸积盘            |
| `#horizon`     | 引力弯折；滑杆实际改变光线积分                     | 保持同一个核心，以对数尺度拉远，显露旋臂              |
| `#web`         | 星系与宇宙网；拖动、方向键环绕、展开网络、选择节点 | 继续探索粒子丝状结构和星系团，或沿原路径回看          |

各章提供简短中文介绍和 NASA 原始资料链接。手机采用下方介绍、上方观测区域；宇宙网可按按钮巡游节点，桌面也可点选节点。正式网站的“只看宇宙”隐藏文字和导航，Escape 或“返回介绍”恢复。

## 连续性与渲染

所有天体在同一个 Three.js 场景中常驻。场景切换不创建新星球，也没有镜头附着的陨石、从星球中钻出的流星、黑屏或白闪遮罩。眼睛与视线使用同一个弧长参数，天体边界、环面倾斜和相机路径均使用世界坐标。移动端改变 FOV，避免为适配画幅移动镜头而穿入物体。

ScrollTrigger 将约 750vh 的正文映射到五段连续路径；每章有停留区间。Lenis 提供惯性滚动，章节跳转为 2.2 秒，镜头保留 1.35 秒的跟随阻尼。热扰动、环面折射、局部引力畸变与径向拉伸处理当前渲染画面；没有重复的贴片转场。

地表和云层纹理由 GPU 生成。星云使用低分辨率体积积分、预烘焙的程序化散射层和暗尘柱，独立深度遮挡防止盖到前景天体。黑洞光线采用数值积分近似，银河有 100,000 个恒星粒子，宇宙网有 52,000 个丝状与星系团粒子；手机降低数量和体积层分辨率。HDR Bloom、色差、ACES 和 FXAA 组成后处理。离屏体积和远处黑洞不会在无可见贡献时继续执行昂贵积分。

几何体、材质、纹理、渲染目标、滚动实例和事件监听均有卸载清理。隐藏页面时暂停渲染、序章时间线、滚动与音频。减少动态效果模式关闭呼吸、持续旋转及转场光学扰动，并缩短滚动惯性；主动探索仍保留。

## 代码结构

- `src/Observatory.jsx`：六章内容、Lenis / ScrollTrigger、可访问控件与导航。
- `src/scene/world.js`：天体坐标、碰撞球、环面坐标系。
- `src/scene/routes.js`：配对眼睛/视线曲线、环缝路径、尺度拉远。
- `src/scene/Universe.jsx`：常驻场景、镜头、交互参数插值和画质控制。
- `src/scene/ObservatoryOptics.jsx`：处理实际帧缓冲的局部光学过渡。
- `src/scene/CosmicWeb.jsx`：弯曲丝状粒子、星系团、节点点选。
- `src/scene/NebulaVolume.jsx`：星云体积、暗尘、遮挡与探照。
- `src/scene/BinaryDawn.jsx`：光球颗粒、日冕、温度响应与日蚀。
- `src/hooks/useEvolution.js`：序章输入锁和进入正式网站的交接。
- `scripts/check-routes.mjs`：十段路径的碰撞、环缝和边界连续性检查。

画面与空间比例为艺术化示意，不是天体物理模拟。帧率取决于设备和画幅；不对所有设备承诺固定 60fps。开发模式下 canvas 的 `data-progress`、`data-position`、`data-collisions` 和 `data-renderer` 可用于排查连续性问题，不显示在产品界面。
